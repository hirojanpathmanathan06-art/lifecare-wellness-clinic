# LifeCare Wellness Clinic Website

A multipage website for LifeCare Wellness Clinic, a private medical clinic, created for HND Unit 13: Website Design & Development (Online Hospital Management System).

## Pages

| Page | File | Purpose |
|------|------|---------|
| Home | `index.html` | Clinic introduction, services, opening hours |
| Patients | `patients.html` | Patient registration and electronic health records |
| Appointments | `appointments.html` | Doctor and nurse schedules, appointment booking |
| Rooms | `rooms.html` | Room availability and room scheduling |
| Billing | `billing.html` | Invoices, payments and balances (staff only) |
| Reception | `reception.html` | Inquiries and patient movement tracking (staff only) |
| Contact | `contact.html` | Contact details and message form |
| Staff Login | `login.html` | Login for clinic staff |

Demo staff account: **staff** / **LifeCare@2026**

## Technologies

HTML5, CSS3 and JavaScript. Data is saved in the browser (localStorage) for this prototype.

LifeCare Wellness Clinic is a fictional clinic used for an academic project.
